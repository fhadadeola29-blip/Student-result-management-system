# Student Result Management System

**Created by:** Fhad Balogun
**Contributor:** Khidir Segun Aileru

A simple menu-driven Python program to register students, record scores for
5 subjects, calculate totals/averages/grades, and save reports.

## How to run (VS Code)
1. Install Python from python.org (tick "Add Python to PATH").
2. In VS Code: File > Open Folder > choose `student_result_system`.
3. Open `main.py` and click the Run (play) button, or in the terminal type:
   `python main.py`

## Files
- `main.py` - menu and program start
- `student.py` - Student class
- `results.py` - total, average, grade
- `storage.py` - load/save JSON (`data/students.json`)
- `reports.py` - report card, class list, statistics, text report
